# Contributing to Proscenium

This repository holds Proscenium's public documentation, changelog and releases. The application source is not published here, so code contributions do not apply.

Bug reports and documentation corrections are welcome as issues. Include the Proscenium version, your Windows version and synthetic traffic only; do not attach real webhook payloads or license keys.

Report security problems privately as described in [SECURITY.md](SECURITY.md).
